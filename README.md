# DSh Open

> **这个软件的全部代码由 DeepSeek 编写**（人的工作只有提需求、试错和拍板）。

一个 Windows 桌面客户端：把 **QQ / B 站**接进来，用本地或云端大模型（Ollama / DeepSeek / 任意 OpenAI 兼容）跟人聊天。

不只是「自动回复」——她记得你说过的事、有自己的人格、有对外规矩（别人怎么套都问不出版主的隐私）、能主动找你，也能按你的指令人工遥控电脑。

> 这个仓库是**源码**：不含 300 MB 的 Electron 运行时，也不含任何人的配置与聊天记录。按下面三步就能跑起来。

## 下载（不想碰命令行就用这个）

**[DSh Open 便携版 · Windows x64](https://github.com/RieMonika/DSh-Open/releases/latest)** —— 约 146 MB 的 zip（最新一版在 Releases 里），解压后双击 `启动.bat` 就能用，不用装 Node、不用装 Electron。

> 没有代码签名，第一次运行 SmartScreen 会拦一下：点「更多信息」→「仍要运行」。数据全在解压目录的 `data\` 里，拷走整个文件夹就是搬家。

## 三步跑起来

1. **下载运行时**（一次性，约 120 MB，需要联网）

   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\fetch-runtime.ps1
   ```

2. **构建**：双击 `构建.bat`（把 `app\` 同步进 `runtime\resources\app`、写 exe 图标、建桌面快捷方式）

3. **启动**：双击 `启动.bat`

第一次打开是**白板**：不认任何人、没有任何 Key、没有表情包、没有记忆——左边栏「教程」里四步就能配完。

全部在软件目录里，删掉文件夹就是删掉全部数据：

- `data\settings.json` — 配置
- `data\dsh-open.db` — 聊天记录、记忆、用量（SQLite）

## 界面里有什么

- **总览**：一进来看到的状态页，显示版本、数据位置、路线图。
- **消息**：统一收件箱。左边是会话（私聊/群），右边是聊天记录，底下能直接发消息。
- **通道**：QQ 接进来、白名单、自动回复、主动聊天、成长、B 站推荐都在这。QQ 走 OneBot 协议，用 NapCat 连；填好地址点「连接」，连上后右上角变「在线」，收到的消息自动进「消息」页。
- **模型**：三套接入随便挑（Ollama 本机 / 硅基流动云 / 自定义 OpenAI 兼容），记忆可以存本机也可以借向量模型按意思检索，人格内置 6 套、可改可自建。最后一块「表情包」管的是自动配图：开不开、多少概率、10 种情绪各自用哪个分组，还能输入一句话试挑一张。
- **能力说明**：能做什么 / 还没做 / 做不到，一目了然，说明文字能自己改。
- **表情包**：扫你本机的表情目录，按情绪分组，点开能直接发给某个会话。右上角「管理」进入管理模式，可以批量改分组、收藏、移到回收站；单张点开能单独改分组、打开文件位置。
- **插件中心**：插件目录、重新扫描、每个插件的启停开关；每个插件带一个权限徽标（PC / Cli / Def / Mem / Stk / Chn / Tool / Data），卡片上默认写「权限：Cli」这种简短形式。标题右边的「权限说明」会把每种权限是干什么的、默认挂到哪个模块列清楚（中文界面里名字后面还带英文原名，比如「人格修正（Personality correction）」）；弹窗最下面有个开关「显示更清晰的归属」，打开后卡片会改写成「归属：客户端 → 客户端本身」。
- **插件卡片右下角的三个点**：点开是管理菜单 —— 打开插件目录 / 重新加载 / 删除插件。删除会弹确认框，确认后把插件文件夹和它自己的数据目录一起删掉（删掉不能恢复）。
- **设置（右下角那个小齿轮）**：界面语言（中/英，切换立即生效）、开机自启动（真写注册表，随时可关）、数据/缓存/日志/插件四个目录的一键打开、关于、恢复默认设置。

窗口大小、最后停留的页面会自动记住，下次打开原样回来。

## 设计原则（以后加功能都按这个来）

1. **一个功能 = 一个文件夹**，功能之间不互相 `require`，要连也通过 `registry` / 事件。
2. **数据只增不改**：新功能只加新字段、新表，旧数据永远能读。
3. **界面只跟桥说话**：界面通过 `preload.js` 暴露的方法拿数据，不直接碰 Node。
4. **加什么都登记**：页面、通道、工具都往 `core/registry.js` 登记，侧栏自动长出来。
5. **每次加完跑自检**：老功能全测一遍，不通过不算完成。
6. **所有写入都在 D 盘。**

## 排障

日志在 `D:\DSh Open\data\logs\`（按天）和 `D:\DSh Open\data\boot.log`。

界面里的报错也会写进日志（前缀 `[界面]`），所以出问题时把最新的日志文件发我就行。

正常启动的日志长这样：

```
---- boot ---- D:\DSh Open\runtime\DShOpen.exe
setPath ok: userData -> D:\DSh Open\data\userData
app ready
settings: 已加载
db: 已启用 SQLite -> D:\DSh Open\data\dsh-open.db
plugins: 扫描完成 1 个插件 sample-hello:disabled
ipc: 已注册通道
ready-to-show
```

看到 `ready-to-show` 说明窗口已经正常渲染。用记事本打开日志就是正常中文，用 PowerShell 看要加 `-Encoding UTF8`。

### v0.29.19 · 修

**细节打磨**：卡住的状态行、露出来的 `pet.title`、重复的标题

翻完整套英文之后又逐页挑了一遍细节，修掉四处：

**主动聊天**：曲线其实一条都没发出去过，现在 QQ 和 B 站共用一套

查「概率曲线能不能跑」的时候挖出三个问题，都不在曲线本身：

- **发不出去的根因**：判断 QQ 在不在线写成了 `status().online`，可 `status()` 返回的是 `status: 'online'`，那个字段永远是空 → 每次都被当成「QQ 还没连上」，静默跳过。所以曲线算得再准也一条没发出去。现在 `status()` 顺手给了 `online` 布尔值，非强制发送也会先看它
- **重启就忘「上次开口」**：这个模块在 `settings.load()` 之前就被 require 了，模块顶层读到的设置是空的，于是每次启动都把「上次开口时间」重置成现在，曲线永远从 0 分钟起算。现在 `start()` 里重新读一次
- **没发出去也不吭声**：`tick` 里 `catch(() => {})` 把失败全吞了。现在发失败会写一条 `proactive: 这一条没发出去 — 原因`

顺便按「通用」的语义把节奏统一了：

- 「主动聊天」里的固定间隔 / 概率曲线 / 免打扰，现在 **QQ 私聊和 B 站私信推荐共用**；两边各按自己的「距上次开口」算，掷骰子也各自计，互不打断
- B 站那边删掉了「隔多久发一条」，它原来那套 240 分钟 + 09:00–23:00 由共享节奏取代
- 实测：临时把间隔改成 15 分钟、免打扰关掉，08:21:45 真的发出一条主动消息，`voice_usage` 之外 `messages #139`、日志 `proactive: 已主动发给 …（等级 4）` 都对上了；30 天模拟里 314 条、中位间隔 100 分钟、没有一条落在免打扰时段

  - `打字停顿`：回答前先「想一下」，1~7 秒不等，不是秒回。
- **群里只认 @**：开关默认开。群里只有 @ 她才会接话，别人闲聊不理。
- **关系（好感度 + 心情）**：成长是「经验/等级」，关系是「温度」。每个人一个好感分（0~100，五档：陌生/眼熟/朋友/要好/亲密），每天还会抽一个心情和想干的事（固定池子，不花 token）。好感会写进给模型的话里，语气会跟着变；好感越高，聊起来越熟络。
- **聊完自己记一笔**：每聊完一轮，后台用本地小模型（`qwen2.5:0.5b`）判断这句话里有没有值得长期记住的事（喜好、习惯、身份、约定），有就自动存进记忆。下次聊天自动带上。模型页有开关和「自动记试试」按钮。

**模型 + QQ**

### 模型页（侧栏「模型」）

三块配置，都在这一页：

1. **接入** —— 用哪个大模型。预置三套，可以同时配好、随时切换：
   - **Ollama**（本机，数据不出门）：装好 Ollama 后默认 `http://127.0.0.1:11434/v1`，模型名例如 `qwen2.5:7b`。
   - **硅基流动 SiliconFlow**（云端）：到 cloud.siliconflow.cn 建 API Key 粘进来，模型名例如 `deepseek-ai/DeepSeek-V3`。
   - **自定义**：任何 OpenAI 兼容接口（vLLM / LM Studio / one-api）。
   每套点「配置」能改地址、模型名、Key，里面有「测试连接」会真的发一次请求，把可用模型列出来。
   Key 只存在本机 `D:\DSh Open\data\settings.json` 里，不上传。
2. **记忆** —— 记忆永远存在本机的 `dsh-open.db`；「记忆方式」只是决定要不要向 Ollama / 硅基流动借向量做语义检索。
   本地模式 = 关键词检索，不联网。下面可以直接「记住」一条，也能删。
3. **人格** —— 说话方式。一套人格 = 系统提示词 + 风格 + 长度 + 禁区。内置 6 套（鲸鱼娘 / 严谨管家 / 傲娇吐槽 / 温柔姐姐 / 猫娘 / 冷静分析），可以改、可以另建、自建的可以删。

### 通道页（侧栏「通道」）

QQ 走 OneBot v11，等于把原来在终端里手敲的那套搬进客户端：

```
NapCat（负责跟腾讯说话） ── ws://127.0.0.1:3001 ──> DSh Open（负责显示和调模型）
```

- 界面上填 WebSocket 地址、Access Token，点「连接」；状态会变成「在线」，并显示登录的 QQ 号和昵称。
- 勾「启动软件时自动连」：下次开机自己连，断了会自动重试（3 秒起，最长 30 秒）。
- 「NapCat 启动程序」处可以选一次 `NapCatWinBootMain.exe`，以后直接在客户端里点「启动 NapCat」，不用再开终端。
  选到 NapCat 的启动器就行，例如 `C:\NapCat\NapCatWinBootMain.exe`。
- 连上之后收到的私聊/群聊消息会存进本地数据库（conversations / messages 两张表），供后面做统一收件箱。

## 这个仓库不会带出你本机的东西

源码里带的是通用写法，不带任何人的账号、路径、聊天记录。为了防止以后改回去，仓库里有两道自动闸门：

- **提交前**：`.githooks/pre-commit` 调 `tools\check-leaks.ps1` 扫一遍要提交的文件，命中就不让提交。clone 下来跑一次 `powershell -File tools\setup-hooks.ps1` 就能启用（或者直接 `git config core.hooksPath .githooks`）
- **推送后**：`.github/workflows/leak-guard.yml` 在 GitHub 上再扫一遍，网页直接改文件也拦得住

两边查的是同一类东西：`C:\Users` 下面那种个人目录、私人邮箱、手机号、像密钥的长串、`~/.dsh` 这类私有目录、以及软件目录之外的绝对路径。想加自己的敏感词，就写进 `cache\private-banlist.txt`（一行一个，这个文件在 `.gitignore` 里，永远不会被提交）。

示例里的号码一律用 `10001`、`12345678` 这种明显是占位的东西。
